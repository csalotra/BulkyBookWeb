# Refresher Project — ASP.NET Core MVC

A simple ASP.NET Core MVC web application that demonstrates essential web development concepts including CRUD operations, Entity Framework Core integration, and Bootstrap-based UI design. This project was built as a **refresher** to revisit and strengthen modern .NET web development skills.

---

## Features

- ASP.NET Core MVC architecture  
- CRUD operations for Categories (Create, Read, Update, Delete)  
- Entity Framework Core with SQL Server  
- TempData-based success/error notifications  
- Responsive layout using Bootstrap 5  
- Toastr.js for popup notifications  
- Razor Views with ASP.NET Tag Helpers  

---

## Main Module: Category Management

This module demonstrates the complete CRUD workflow, including:

- Listing existing categories  
- Creating new entries  
- Editing existing records  
- Deleting records  
- Displaying real-time success or error notifications using Toastr  

---

## Tech Stack

- ASP.NET Core MVC  
- Entity Framework Core  
- SQL Server  
- Bootstrap 5  
- Toastr.js  

---
